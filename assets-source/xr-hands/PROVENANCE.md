# Standard XR hands

The runtime hands are the `generic-hand` meshes from the immersive-web WebXR Input Profiles assets package, `@webxr-input-profiles/assets` 1.0.20 (MIT, see `LICENSE.md`). They are the hands three.js's `XRHandModelFactory` loads by default on Quest; WebXR pages cannot use the Quest system hand renderer itself. The model was added upstream on 2021-04-27 ("Add generic WebXR hand model") and its bones were renamed to the WebXR joint names, metacarpals matched to OpenXR, and skinning added in later upstream commits through 2022-12-02.

The owner chose them on 2026-11-07 after rejecting the authored cartoon hand ("can you just use normal XR hands provided by meta"), approving a render of the meshes posed with the captured Quest fist, pinch and open-palm joints.

The files are served byte-for-byte; the runtime requests them with `?v=` plus the first 12 hex digits of each hash (`STANDARD_HAND_ASSET_URLS` in `src/xr/standard-hand.ts`, checked by `tests/standard-hand.test.ts`). Each mesh has 25 bones named after the WebXR joints, and the runtime places every bone on its tracked joint. Controller mode poses the same bones from `src/xr/standard-hand-controller-poses.json`, generated by `scripts/build-standard-hand-poses.ts` from the captured relaxed and fist joints in `tests/fixtures/`.
